# Personal Expense Tracker

A web-based Expense Tracker developed using PHP, MySQL, HTML, CSS and JavaScript.

## Features

- User Registration & Login
- Add Expenses
- Edit Expenses
- Delete Expenses
- Search Expenses
- Monthly Expense Filter
- Pie Chart Visualization
- Expense Report Download
- Dark Mode

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Chart.js
